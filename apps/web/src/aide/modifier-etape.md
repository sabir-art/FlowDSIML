---
title: Modifier une étape
section: Éditeur
summary: Titre, bulle, zone de clic
---

Sélectionnez une étape dans la liste de gauche. Le panneau **Étape** de droite permet de changer :

- le **titre** de l’étape ;
- le **texte de la bulle**, qui peut utiliser vos variables, par exemple {{first_name}} ;
- la **zone de clic** (hotspot), à déplacer ou redimensionner directement sur l’image.

Les modifications sont enregistrées automatiquement. **Ctrl Z** annule la dernière.

## Réorganiser

Glissez une étape dans la liste pour la déplacer. Le menu **+** ajoute une étape de texte, une pop-up ou une image.
