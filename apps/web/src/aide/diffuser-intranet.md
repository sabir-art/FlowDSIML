---
title: Diffuser sur un intranet ou par e-mail
section: Diffusion
summary: Code à intégrer, widget, e-mail
---

Le menu **⋯** > **Diffuser** propose plusieurs canaux :

- **Intranet** : un code à coller dans une page de votre intranet ;
- **Widget** : un bouton d’aide qui ouvre la démo ;
- **E-mail** : un lien et une image à insérer dans un message.

Tous les canaux utilisent la version publiée. Republiez pour mettre à jour la démo partout.
