---
title: Accessibilité des démos
section: Accessibilité
summary: Clavier, lecteurs d’écran, contrastes
---

Le lecteur TutoClick se pilote au clavier : **→** pour avancer, **←** pour revenir, **Tab** pour atteindre les boutons.

Pour des démos accessibles :

- donnez un titre clair à chaque étape ;
- écrivez des bulles courtes, qui disent quoi faire ;
- gardez un contraste suffisant si vous changez les couleurs.

Le lecteur respecte le réglage « réduire les animations » du système.
