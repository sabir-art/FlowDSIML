Dans **Nouvelle démo**, choisissez **Partir d’un modèle**. Un modèle apporte les chapitres, les étapes et leurs textes ; il ne reste qu’à capturer les écrans.

## Étapes « À capturer »

Les étapes qui demandent une capture sont marquées **À capturer**. Dans l’extension, choisissez **Compléter** puis la démo : chaque clic remplit l’étape suivante, dans l’ordre. Vous pouvez aussi importer une image depuis l’éditeur.

Tant qu’une étape reste à capturer, la démo ne peut pas être publiée.

## Vos propres modèles

Dans l’éditeur, menu **⋯** puis **Enregistrer comme modèle**. Sans les captures (recommandé), aucune donnée de la démo d’origine n’est copiée. Le modèle est visible par tous les membres de l’espace.
