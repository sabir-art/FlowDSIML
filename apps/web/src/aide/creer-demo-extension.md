---
title: Créer une démo avec l’extension
section: Démos
summary: Capturer, flouter, envoyer
---

L’extension TutoClick crée une démo à partir de vos clics dans votre logiciel.

## Capturer

1. Ouvrez la page de votre logiciel dans le navigateur.
2. Cliquez sur l’icône TutoClick, choisissez l’espace et donnez un titre à la démo.
3. Cliquez sur **Démarrer la capture**. Chaque clic dans l’onglet crée une étape, avec la position du clic.
4. Cliquez sur **Terminer** dans la fenêtre de l’extension (ou Alt + Maj + S).

## Vérifier avant l’envoi

Rien n’est envoyé pendant la capture. À la fin, l’écran de vérification montre les données personnelles repérées (noms, téléphones, adresses e-mail…). Elles sont floutées dans l’image avant l’envoi. Vous pouvez décocher un faux positif ou ajouter une zone.

## Ensuite

La démo s’ouvre dans l’éditeur, en brouillon. Elle n’est visible que de votre espace tant qu’elle n’est pas publiée.
