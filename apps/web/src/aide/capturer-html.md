Une capture HTML copie la structure des pages de votre logiciel, au lieu d’une simple image. Les textes et les données restent modifiables, et la page reste nette sur tous les écrans. Elle sert aux types **Démo HTML** et **Sandbox**.

> Capturez uniquement des logiciels que vous êtes autorisé à reproduire. Certaines structures interdisent la copie HTML de leurs écrans : utilisez alors des captures d’écran.

## Capturer

1. Dans **Nouvelle démo**, choisissez **Démo HTML** ou **Sandbox**, puis la source **Capturer avec l’extension**.
2. Dans l’extension, choisissez **Capture HTML**, parcourez les pages, puis vérifiez la capture avant l’envoi.

## Ce qui est retiré de chaque page

Chaque page est nettoyée deux fois, dans votre navigateur puis sur le serveur : scripts, cadres intégrés, actions au clic et adresses d’envoi des formulaires sont retirés. Les données personnelles repérées sont remplacées et floutées. Rien de la page capturée ne peut s’exécuter dans la démo.

## Réglage de l’espace

Dans **Paramètres › Sécurité › Captures HTML**, un admin peut autoriser les captures HTML partout, seulement sur certains domaines, ou les désactiver. Le réglage est appliqué par l’app, l’extension et le serveur. Les démos HTML et les Sandbox déjà créés restent lisibles.
