# TutoClick — identité (logo fourni par le client)

Nom officiel : **TutoClick** (graphie du logo client : « Tuto » + « Click », C majuscule).

| Fichier | Usage |
|---|---|
| `logo-tutoclick.svg` | Logo de référence fourni par le client (fond clair) |
| `logo-tutoclick-sombre.svg` | Dérivé pour fond sombre (« Tuto » en blanc), même dessin |
| `symbole-tutoclick.svg` | Symbole seul (bulle + curseur + éclat), pour favicon, icônes de l'extension et avatar d'app |

Couleurs du logo : bordeaux `#A52B60` → `#7D204C` (dégradé de la bulle), orange `#E49A32`, bleu `#4A9BCB`, vert `#91B83E`, encre `#25232A`.
Le texte utilise la police Inter, qu'il faut vectoriser pour la production (la Lead UX s'en charge).
Le dossier `propositions/` contient d'anciennes pistes, non retenues.
