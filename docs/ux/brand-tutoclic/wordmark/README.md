# Wordmark « Tutoclic » (préparation, en attente du choix du logo)

Le texte est vectorisé (contours), en Plus Jakarta Sans 800. Les glyphes sont mis en forme par HarfBuzz avec le crénage de la police. La police est sous licence SIL OFL 1.1, ce qui autorise la vectorisation dans un logo. Il n'y a pas de dépendance de police à l'usage.

| Fichier | Usage | « Tuto » | « clic » |
|---|---|---|---|
| `tutoclic-wordmark.svg` | Fonds clairs | encre `#080808` | prune `#A3195B` (≥ 6,5:1 sur `#EEF2F6`) |
| `tutoclic-wordmark-sombre.svg` | Fonds sombres | blanc `#FFFFFF` | vert DSI `#95C11F` (≥ 9:1 sur `#0B0D10`) |
| `tutoclic-wordmark-mono.svg` | Une couleur | `currentColor` | `currentColor` |

- **viewBox** : 3965 × 820, avec une marge de 20 unités. La ligne de base est à 800 unités du haut. Il n'y a pas de jambage descendant.
- **Taille minimale** : 18 px de haut à l'écran (vérifié sur `apercu.html`).
- **Zone de protection** : la hauteur du « o » tout autour.
- Le symbole n'est **pas** inclus : il dépend du choix client parmi les propositions de `../propositions/`. Le logo de l'application (`logo-app*.svg`) n'a pas été modifié.
