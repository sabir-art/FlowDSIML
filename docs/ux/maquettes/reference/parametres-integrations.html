L'adresse doit commencer par https://. Les adresses internes (localhost, réseau privé) sont refusées.
Événements à envoyer

Format : { id, type, created_at, data }, délai de 10 s par envoi. Les données personnelles ne sont envoyées qu'avec les événements qui les concernent.
