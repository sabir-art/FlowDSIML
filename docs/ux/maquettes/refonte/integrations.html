Relais vers votre outil d'analytics

Le player envoie ses événements à la page hôte. Ce script les transmet à l'outil déjà installé sur votre site : aucun cookie ni traceur ajouté par TutoClick.

window.addEventListener('message', (e) => {
  if (e.origin !== 'https://demos.tutoclick.example' || e.data?.source !== 'tutoclick') return;
  window._paq?.push(['trackEvent', 'TutoClick', e.data.type, e.data.demoTitle]);
});

Pilotage du player depuis la page hôte

Avec le script d'intégration, l'objet TutoClick permet d'ouvrir une démo, d'aller à une étape, de passer des variables et d'écouter les événements.

const player = TutoClick.get('creer-une-fiche-usager');
player.open({ step: 3, variables: { first_name: 'Léa' } });
player.goTo(5);          // aller à l'étape 5
player.on('step', (e) => console.log(e.index, e.title));
player.on('complete', () => afficherLaSuite());
Méthode ou événementRôle
open(options)Ouvre la démo (pop-up ou dans la page), à une étape donnée, avec des variables
goTo(n) · next() · prev() · close()Navigation
on('ready' | 'step' | 'choice' | 'lead' | 'cta' | 'complete' | 'quiz')Écoute des événements (mêmes données que le relais analytics)

Fonctionne uniquement depuis les sites autorisés. Les données personnelles d'un lead ne sont jamais transmises à la page hôte, seulement l'événement.
