L48-G : trois types de contenu

TutoClick produit trois types de contenu, présentés comme tels à la création, dans la navigation et sur les cartes : la démo par captures (guidée, une image par étape), la démo HTML (guidée, des pages HTML modifiables) et le Sandbox (pages HTML reliées, exploration libre, sans étapes imposées). Le Sandbox relie déjà les liens identiques et affiche un plan ; il signale désormais les liens vers des pages non capturées. Données fictives.

1. « Nouvelle démo », étape 1 : choisir le type

2. Étape 2 : choisir la source (exemple : Sandbox)

3. Navigation et cartes : le type est visible partout

4. Plan du Sandbox : liens vers des pages non capturées

5. En sombre et sur mobile

Règles

  • Les trois types gardent le même vocabulaire partout : « Démo par captures », « Démo HTML », « Sandbox ». Une ligne d'explication et une illustration schématique chacun.
  • Le type est choisi en premier ; la source (extension, images, modèle, IA, vide) en second, filtrée selon le type.
  • Navigation : « Démos » (captures et HTML, guidées) et « Sandbox » sont deux entrées du groupe Contenus ; un filtre « Type » distingue captures et HTML dans Démos.
  • Plan du Sandbox : liens identiques reliés automatiquement (existant), pages « À relier » (existant), et nouvelle liste « Liens sans page » avec Capturer, Relier ou Laisser le message.
