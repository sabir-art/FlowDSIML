L46 : variables lisibles

Une variable apparaît comme une pastille avec un nom en français (« Prénom du visiteur »), jamais sous la forme {{first_name}}. On l'insère avec « + Variable », depuis un catalogue groupé, avec une description et un exemple pour chacune. Chaque pastille a une valeur de repli. L'aperçu montre les exemples. La mise en forme est visuelle : jamais de ** visibles. Données fictives.

Règles

  • Insérer : « + Variable » dans la barre du champ, ou en tapant { dans le texte. Le catalogue s'ouvre sous le curseur ; flèches, Entrée pour insérer, Échap pour fermer.
  • Une pastille est un seul caractère pour le curseur : flèches pour la passer, Retour arrière la sélectionne, un second appui la supprime d'un coup, glisser-déposer ou couper-coller pour la déplacer. Un clic (ou Entrée sur la pastille sélectionnée) ouvre son réglage.
  • Valeur de repli : utilisée si la valeur est inconnue pour ce visiteur. Proposée selon la variable (« vous », « votre structure »…) ; vide si l'on veut que le mot disparaisse.
  • Aperçu : « Exemples » par défaut (Camille, Acme Formation…), ou « Valeurs de repli » pour vérifier la phrase quand on ne sait rien du visiteur. Les valeurs insérées sont légèrement surlignées dans l'éditeur seulement.
  • Une variable supprimée de l'espace reste visible dans le texte en pastille barrée « Variable supprimée » : jamais de clé technique.
