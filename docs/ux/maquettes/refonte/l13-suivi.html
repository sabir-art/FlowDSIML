Une formation est une suite de démos (modules). Un module sans quiz est validé à la dernière étape, un module avec quiz quand le quiz est réussi.

Les structures regroupent les apprenants (antenne, service…). Un apprenant est rattaché automatiquement selon le domaine de son e-mail.
