---
title: Modifier une étape
section: Éditeur
summary: Titre, texte de la bulle, hotspot
---

1. Sélectionnez l'étape dans la liste de gauche.
2. Dans le panneau **Étape**, changez le titre et le texte de la bulle. Le texte peut contenir des variables (voir « Adapter le texte à chaque visiteur »).
3. Déplacez ou redimensionnez le hotspot directement sur la capture.

Tout est enregistré automatiquement ; Ctrl Z annule la dernière modification. Pour réorganiser, glissez l'étape dans la liste.
