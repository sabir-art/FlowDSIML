---
title: Adapter le texte à chaque visiteur
section: Éditeur
summary: Insérer une variable, choisir une valeur de repli
---

Une variable est un mot qui change selon le visiteur : « Bonjour Prénom du visiteur » devient « Bonjour Camille ».

1. Dans le texte d'une bulle, cliquez sur **+ Variable**, ou tapez la touche {.
2. Choisissez la variable dans la liste, par exemple **Prénom du visiteur**. Une pastille apparaît dans le texte.
3. Cliquez sur la pastille pour choisir le texte affiché **si la valeur est inconnue**, par exemple « vous ».
4. Au-dessus du canevas, passez de **Exemples** à **Valeurs de repli** pour voir ce que lira un visiteur inconnu.

Les valeurs viennent d'un lien personnalisé ou de l'adresse de la démo. Vos propres variables (par exemple Nom du logiciel) se créent dans **Paramètres > Variables**.
